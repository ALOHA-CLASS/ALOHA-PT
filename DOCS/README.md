# ALOHA Slide Studio

**개발자와 IT 강사를 위한 웹 기반 프레젠테이션 편집기**

ALOHA Slide Studio는 코드 예제와 기술 설명이 포함된 강의용 프레젠테이션을 웹 브라우저에서 제작·편집하고, 발표 및 파일로 내보낼 수 있도록 하는 프로젝트입니다. PowerPoint와 Canva의 편집 경험을 참고하되, 개발 강의에 필요한 코드 블록 편집과 기술 콘텐츠 재사용에 초점을 둡니다.

> 프로젝트 상태: 기획 및 기술 기준선 수립 단계
>
> 이 문서는 목표 기능과 권장 개발 구조를 정의합니다. 아래 기능이 실제 구현되었다는 의미는 아닙니다.

## 주요 목표

- 16:9 슬라이드를 WYSIWYG 방식으로 편집합니다.
- 텍스트, 이미지, 도형, 코드 블록을 독립된 요소로 배치합니다.
- 슬라이드 마스터, 레이아웃, 테마를 분리해 일관된 디자인을 유지합니다.
- 코드 블록의 언어별 구문 강조와 편집 경험을 제공합니다.
- 요소 애니메이션과 발표 모드를 지원합니다.
- 프로젝트를 브라우저 로컬 저장소에 보관하고 JSON 형식으로 백업·복원합니다.
- PPTX 및 PDF 내보내기를 단계적으로 지원합니다.

## 핵심 설계 원칙

1. **Local-first**: 초기 버전은 별도 백엔드 없이 브라우저에서 동작합니다.
2. **JSON as source of truth**: 슬라이드의 구조와 콘텐츠는 직렬화 가능한 데이터로 관리합니다.
3. **Editor / Renderer 분리**: 편집 UI와 발표·내보내기 렌더러가 동일한 슬라이드 데이터를 사용합니다.
4. **확장 가능한 요소 모델**: 새 요소 종류와 애니메이션을 기존 데이터 구조를 크게 바꾸지 않고 추가할 수 있도록 설계합니다.
5. **내보내기 독립화**: PPTX/PDF 변환 로직을 편집 화면 및 상태 관리 코드와 분리합니다.

## 기술 스택 요약

| 영역 | 기술 | 역할 |
|---|---|---|
| 프런트엔드 | React + TypeScript + Vite | 애플리케이션과 편집 UI |
| 스타일 | Tailwind CSS + shadcn/ui | 화면 스타일과 UI 컴포넌트 |
| 아이콘 | Lucide React | 도구 모음 및 패널 아이콘 |
| 상태 관리 | Zustand | 프로젝트·슬라이드·선택 상태 |
| 드래그/정렬 | dnd-kit | 요소 이동, 슬라이드 순서 변경 |
| 리치 텍스트 | Tiptap | 텍스트 요소 편집 확장 후보 |
| 코드 편집 | Monaco Editor | 코드 요소 편집 |
| 구문 강조 | Shiki | 코드 표시 및 내보내기용 렌더링 후보 |
| 로컬 저장 | IndexedDB | 프로젝트 및 이미지 바이너리 저장 |
| PPTX | PptxGenJS | PowerPoint 파일 생성 |
| 애니메이션 | Motion for React | 편집·발표 화면의 전환 효과 |

세부 선택과 대안은 [`TECH_STACK.md`](./TECH_STACK.md)를 참고하세요.

## 실행 환경

- Node.js: 프로젝트에서 사용하는 Vite 버전이 지원하는 LTS 버전
- 패키지 관리자: npm 기준으로 설명합니다. pnpm 또는 yarn을 사용해도 됩니다.
- 브라우저: 최신 Chromium, Firefox, Safari 계열 브라우저를 목표로 합니다.

## 설치 및 실행

저장소를 내려받은 뒤 프로젝트 루트에서 실행합니다.

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 타입 검사
npm run typecheck

# 정적 검사(oxlint)
npm run lint

# 단위 테스트(Vitest)
npm run test

# 빌드 결과 미리 보기
npm run preview
```

개발 서버를 실행한 뒤 브라우저에서 `http://localhost:5173`을 엽니다. 모든 데이터는 해당 브라우저의 IndexedDB에 저장됩니다.

## 현재 구현 상태 (0.2.0)

- 프로젝트 목록, 편집기(텍스트·도형·이미지·코드 요소), 자동 저장, JSON 백업·복원, 발표 모드, PPTX·PDF 내보내기 코드가 작성되어 있습니다.
- 타입 검사, 린트, 단위 테스트(71개), 프로덕션 빌드를 통과합니다.
- 브라우저에서 직접 확인한 범위는 프로젝트 생성, 텍스트·도형·코드 추가, 자동 저장, Monaco 코드 편집까지입니다. 나머지 기능의 검증 상태는 [`TASKS.md`](./TASKS.md)에 기능별로 표시했습니다.

## 기본 사용 흐름(목표 UX)

1. 새 프레젠테이션을 생성합니다.
2. 테마와 슬라이드 레이아웃을 선택합니다.
3. 슬라이드에 텍스트·이미지·도형·코드 요소를 추가합니다.
4. 캔버스에서 요소를 이동·크기 조절하고 속성 패널에서 세부 값을 수정합니다.
5. 발표 모드로 결과를 확인합니다.
6. 프로젝트를 로컬에 저장하거나 JSON으로 백업합니다.
7. 지원되는 내보내기 형식으로 파일을 생성합니다.

## 디렉터리 구조

```text
src/
├── app/                    # 앱 진입점, 해시 라우팅
├── components/ui/          # shadcn/ui 공통 컴포넌트
├── domain/                 # 순수 함수: 프로젝트 조작, 검증, 마이그레이션, 애니메이션 계획
├── features/
│   ├── projects/           # 프로젝트 목록 화면
│   ├── editor/             # 편집기 화면, 도구 모음, 단축키, 편집 액션
│   ├── canvas/             # 슬라이드 캔버스, 썸네일, 텍스트 편집 오버레이
│   ├── slides/             # 슬라이드 목록 패널
│   ├── elements/           # 텍스트·이미지·도형·코드 요소 렌더러
│   ├── inspector/          # 속성 패널(요소·슬라이드·애니메이션·레이어)
│   ├── code-editor/        # Monaco 편집 창, Shiki 구문 강조
│   ├── presentation/       # 발표 모드
│   └── export/             # 내보내기 실행(JSON·PPTX·PDF 인쇄)
├── stores/                 # Zustand 스토어(projectStore, editorStore)
├── services/
│   ├── storage/            # IndexedDB Repository, Asset URL 캐시
│   └── export/             # JSON 백업, PPTX 변환기
├── types/                  # 공통 타입과 데이터 모델
├── utils/                  # 순수 유틸리티 함수
└── styles/                 # 전역 스타일과 디자인 토큰
```

## 개발 상태 및 기여 규칙

- 기능을 구현하기 전 관련 데이터 모델과 영향 범위를 먼저 확인합니다.
- 캔버스 렌더링은 가급적 순수한 데이터 입력을 받는 컴포넌트로 유지합니다.
- UI 컴포넌트에서 IndexedDB를 직접 호출하지 않고 Repository 계층을 사용합니다.
- 새 요소 종류를 추가하면 타입, 생성 함수, 렌더러, 속성 패널, 저장·복원, 내보내기 처리를 함께 검토합니다.
- 기능 완료 시 `TASKS.md`와 `CHANGELOG.md`를 갱신하고 빌드·테스트 결과를 기록합니다.
