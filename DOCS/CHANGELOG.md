# CHANGELOG.md

이 문서는 사용자에게 보이는 기능 변경과 개발 기준의 주요 변경 사항을 기록합니다. 날짜는 한국 시간 기준으로 작성합니다.

변경 유형:

- `Added`: 새 기능 추가
- `Changed`: 기존 기능 또는 동작 변경
- `Fixed`: 오류 수정
- `Removed`: 기능 제거
- `Docs`: 문서 변경
- `Technical`: 내부 구조·개발 환경 변경

## [Unreleased]

## [0.2.0] - 2026-11-25

첫 구현 버전입니다. 아래 기능은 코드로 작성되어 타입 검사·린트·단위 테스트·빌드를 통과했습니다. 다만 브라우저에서 직접 확인한 범위는 일부이므로, 기능별 검증 상태는 `TASKS.md`를 기준으로 봅니다.

### Added

- 프로젝트 목록 화면: 새 프로젝트 생성, 이름 변경, 삭제, JSON 백업 내보내기·가져오기.
- 편집기 화면: 상단 도구 모음, 슬라이드 목록, 1280 × 720 캔버스(확대·축소·맞춤), 속성 패널.
- 슬라이드 추가·복제·삭제·순서 변경, 레이아웃 선택, 배경색, 발표자 노트.
- 텍스트·도형(사각형, 둥근 사각형, 타원, 선, 화살표)·이미지·코드 요소의 생성, 이동, 크기 조절, 회전, 속성 편집.
- 코드 요소: Monaco Editor 편집 창(지연 로딩)과 Shiki 구문 강조, 언어 20종·테마 5종, 줄 번호·자동 줄바꿈 설정.
- 테마·마스터·레이아웃 모델과 기본 템플릿, 테마 선택.
- IndexedDB 자동 저장(debounce)과 저장 상태 표시, 이미지 Asset 저장.
- 이미지를 포함한 JSON 백업·복원과 잘못된 파일 검증.
- 발표 모드: 전체 화면, 키보드 이동, 요소 애니메이션(나타나기, 페이드 인/아웃, 슬라이드 인, 확대), 슬라이드 전환 효과.
- PPTX 내보내기(PptxGenJS)와 브라우저 인쇄 기반 PDF 내보내기.
- 실행 취소·다시 실행, 다중 선택, 정렬, 레이어 패널, 복사·붙여넣기, 키보드 단축키.

### Technical

- Vite 8 + React 19 + TypeScript 7(strict) 기반으로 프로젝트를 초기화했습니다.
- TypeScript 7을 지원하는 oxlint를 린터로 사용합니다(ESLint 대체).
- 순수 함수로 이루어진 도메인 계층(`src/domain`)과 Zod 스키마 검증, 마이그레이션 구조를 추가했습니다.
- Vitest 단위 테스트 71개를 추가했습니다(도메인 로직, 검증, 저장소·백업, 구문 강조, 애니메이션, PPTX 변환).
- Monaco Editor, PptxGenJS, 인쇄 화면을 별도 청크로 분리해 필요할 때만 불러옵니다.

### Known Limitations

- PPTX: 글꼴은 포함되지 않고, 애니메이션·전환 효과는 변환되지 않습니다. 마스터 요소는 각 슬라이드에 복사되며, 외부 URL 이미지는 제외됩니다.
- PDF: 브라우저 인쇄 대화상자에서 "PDF로 저장"을 선택하는 방식입니다.
- 마스터/레이아웃 편집 UI, 그룹화, 간격 맞춤, 단축키 도움말, 발표자 보기는 아직 없습니다.

### Docs

- 프로젝트 소개 및 실행 방법을 정의했습니다.
- 전체 개발 로드맵과 단계별 완료 기준을 정리했습니다.
- 프런트엔드 모듈, 상태 관리, 저장소, 렌더링 및 내보내기 아키텍처를 정의했습니다.
- 프로젝트 JSON 데이터 모델 초안을 작성했습니다.
- 기술 스택과 추가 라이브러리 도입 기준을 정리했습니다.
- 개발 진행 상황을 관리할 작업 목록을 작성했습니다.
- 구현 결과에 맞춰 `TASKS.md`, `TECH_STACK.md`, `DATA_MODEL.md`, `README.md`를 갱신했습니다.

## [0.1.0] - 2026-11-25

### Added

- ALOHA Slide Studio의 제품 목표와 초기 MVP 범위를 정의했습니다.
- React + TypeScript + Vite 기반 Local-first 개발 방향을 수립했습니다.
- 1280 × 720(16:9) 기준 캔버스 정책을 정의했습니다.
- 텍스트·이미지·도형·코드 요소의 데이터 모델 초안을 정의했습니다.
- 슬라이드 마스터·레이아웃·테마 구조를 정의했습니다.
- JSON 백업·복원과 IndexedDB 저장 전략을 정의했습니다.
- PPTX·PDF 내보내기를 위한 독립 Exporter 구조를 정의했습니다.

### Notes

- 이 버전은 문서 및 설계 기준선입니다.
- 제품 기능이 실제 구현되었다는 의미는 아닙니다.
- 구현 완료 여부는 `TASKS.md`와 실제 코드·테스트 결과를 기준으로 관리합니다.
