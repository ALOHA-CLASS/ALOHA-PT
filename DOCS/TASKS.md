# TASKS.md

이 문서는 개발 작업의 현재 상태를 관리합니다. 기능 구현 상태를 임의로 완료 처리하지 않고 코드·테스트 결과를 확인한 뒤 변경합니다.

## 상태 정의

- `TODO`: 대기
- `IN_PROGRESS`: 진행 중
- `DONE`: 완료 및 검증 완료
- `BLOCKED`: 외부 결정 또는 선행 작업으로 보류

체크박스 표기:

- `[x]`: 구현했고 자동 테스트 또는 브라우저에서 동작을 확인했습니다. (`DONE`)
- `[ ] … (구현됨 · 검증 필요)`: 코드는 작성되어 타입 검사·린트·빌드를 통과하지만, 브라우저에서 직접 동작을 확인하지 못했습니다. (`IN_PROGRESS`)
- `[ ]`: 아직 구현하지 않았습니다. (`TODO`)
